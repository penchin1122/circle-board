# 明治就活サークル 運営ボード — 公開までの手順

運営メンバー専用のサイトです。Googleアカウントでログインし、管理者（佐藤）が承認した人だけが使えます。
画面は GitHub Pages、ログインとデータ保存は Firebase（無料の Spark プラン）で動きます。クレジットカードの登録は不要です。

## 権限のまとめ

| 機能 | 見られる人 | 編集できる人 |
|---|---|---|
| ホーム | 承認済みメンバー全員（人ごとに内容が変わる） | — |
| 業務カレンダー | 承認済みメンバー全員 | 登録した本人／管理者。担当者は「完了」だけ切り替え可 |
| KPI | 項目ごとに指定した人＋担当者 | 目標の設定は管理者のみ。週次の進捗は担当者と管理者 |
| 収支 | 管理者＋「収支の閲覧」をONにした人 | 管理者のみ |
| メンバー・設定 | 管理者のみ | 管理者のみ |

これらは画面で隠しているだけではありません。`firestore.rules`（サーバー側のルール）で、権限のない人にはデータそのものを返さないようにしています。

---

## 1. Firebaseプロジェクトを作る（約10分）

1. https://console.firebase.google.com を開き、管理者にするGoogleアカウントでログインする
2. 「プロジェクトを作成」→ 名前は `meiji-circle-board` など → Google アナリティクスは **オフ** で作成
3. 左メニュー「構築」→ **Authentication** →「始める」→ ログイン方法で **Google** を選んで有効にし、サポートメールを選んで保存
4. 左メニュー「構築」→ **Firestore Database** →「データベースを作成」
   - ロケーション：**asia-northeast1（東京）**
   - **本番環境モード** を選ぶ
5. Firestore の「**ルール**」タブを開き、中身を全部消して `firestore.rules` の内容を貼り付ける
   - `'ADMIN_EMAIL'` を管理者のGmailアドレスに書き換える（例：`'satoakira.example@gmail.com'`）。引用符 `' '` は残す
   - 「公開」を押す
6. 歯車アイコン →「プロジェクトの設定」→ 下の「マイアプリ」で **ウェブ（`</>`）** を追加
   - アプリ名は何でもよい。Firebase Hosting のチェックは不要
   - 表示された `firebaseConfig` の値を `config.js` に貼り付ける
   - `config.js` の `ADMIN_EMAILS` にも、手順5と同じGmailアドレスを入れる

> `config.js` の apiKey などは公開されても問題ない値です（Firebaseの仕様）。データを守っているのは手順5のルールです。

## 2. GitHub Pages で公開する（約5分）

1. GitHub で新しいリポジトリを作る（例：`circle-board`）。無料プランで Pages を使うには **Public** にする必要があります
2. このフォルダの中身（`index.html` `app.js` `styles.css` `config.js` `firestore.rules` `README.md`）をアップロードする
   - **収支のCSVはリポジトリに入れないでください**（Publicだと誰でも見られます）
3. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存
4. 数分後に `https://ユーザー名.github.io/circle-board/` で開けるようになる
5. Firebase に戻り、Authentication →「設定」→「**承認済みドメイン**」に `ユーザー名.github.io` を追加する（これを忘れるとログインできません）

## 3. 最初の設定

1. 公開したURLを開き、管理者のGoogleアカウントでログインする（右上に「（管理者）」と出ればOK）
2. 「収支」→「CSVを取り込む」で `初期データ_収支.csv` を選ぶ（Notionにあった4件）
3. 「設定」で定例業務やカテゴリを確認する
4. 「KPI」で今月のKPIを作る。項目ごとに「担当者」と「表示できる人」を選ぶ

## 4. メンバーを招待する

1. 運営メンバーにURLを送り、Googleでログインしてもらう
2. 管理者の画面の「メンバー」タブに「承認待ち」で出るので、本人か確認して「承認する」
3. 表示名を整える（例：赤羽）。収支を見せたい1人だけ「収支の閲覧」をONにする
4. 抜けた人は「利用停止」にすると、その瞬間から何も見られなくなる

## 5. 公開後に一度だけやってほしい確認

この環境ではルールの自動テストができなかったため、公開後に次の確認をお願いします。2つ目のGoogleアカウント（またはメンバーの協力）で試してください。

- [ ] 承認前のアカウントでは「承認待ちです」と表示され、何も見えない
- [ ] 承認後、そのアカウントに「収支」「メンバー」「設定」タブが出ない
- [ ] そのアカウントで、他の人が登録した業務の「保存」が拒否される（「詳細」表示になる）
- [ ] 表示できる人に入れていないKPIが、そのアカウントのKPIタブに出ない
- [ ] 「収支の閲覧」をONにすると、収支タブが出るが「収支を記録」ボタンは出ない

どれかがおかしければ、画面のエラーメッセージを添えて連絡してください。

## 料金の目安

Firebase の無料枠（1日あたり読み取り5万回・書き込み2万回）は、10人程度の運営なら十分です。上限を超えても勝手に課金されることはなく、その日は止まるだけです。
